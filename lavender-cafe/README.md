# Lavender Bakery & Café — enhanced site

Open the folder in VS Code and double-click `index.html`, or use the **Live Server** extension (right-click index.html > Open with Live Server).

## Structure
- index.html
- css/style.css  (lavender theme, animations, dark mode)
- js/main.js     (all features; edit the CONFIG block and MENU array at the top)

## Things to customise (top of js/main.js)
- `CONFIG.hours`, `CONFIG.whatsappNumber`, `CONFIG.currency`, `CONFIG.taglines`
- `MENU` items, names, prices and images
